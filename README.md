# BookOS: Skylake and Intel Legacy

BookOS is working toward running Googlebook OS on Skylake-class hardware and older Intel laptops. The first legacy target is Sandy Bridge and Ivy Bridge: AVX-capable CPUs without AVX2.

**Development status:** early porting work. There is no tested BookOS image or complete build flow in this repository yet. The Sandy/Ivy Bridge target is not supported until the kernel emulator and full boot path are verified.

See the [installation guide](INSTALL.md) for the planned build-your-own and USB-flash flow. It is labeled as a draft and will be updated when the build scripts are ready.
